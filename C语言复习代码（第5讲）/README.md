- 实测环境：VS2022（v143 工具集）+ x64

## 运行方法

1. 用 VS2022 打开 `01-数组.sln`，配置选 `x64`，按 `F5` 运行
2. 命令行编译（可选）：

   ```
   MSBuild 01-数组.sln /p:Configuration=Debug /p:Platform=x64
   ```

## 速记卡（来自博客）

| 知识点 | 记这一句 |
| --- | --- |
| 下标 | 从 0 开始，最后一个是 n-1 |
| 元素个数 | `sizeof(arr)/sizeof(arr[0])` |
| 内存 | 一维连续；二维也连续（按行） |
| 初始化 | 不完全补 0；大小可省、列不能省 |
| 变长数组 | 变量定大小、不能初始化、VS 不支持 |

## 说明

- 字符汇聚的 `Sleep(1000)` 只是让动画慢一点，去掉不影响结果；二分查找的 mid 用了防溢出的 `left + (right - left) / 2` 写法
- 地址每次运行结果不同（系统随机化），相邻差值固定
