# C语言复习：分支和循环（第 3~4 讲）配套代码

对应博客《C语言复习笔记：分支和循环一篇全通》的经典习题代码，单文件版本，打开即用。

- 实测环境：VS2022（v143 工具集）+ x64
- 源码：`01-分支和循环\main.c`（UTF-8 带 BOM，中文注释不乱码）
- 结构：一个解决方案 + 一个 main.c，无多余模块

## 运行方法

1. 用 VS2022 打开 `01-分支和循环.sln`，配置选 `x64`，按 `F5` 运行
2. 命令行编译（可选）：

   ```
   MSBuild 01-分支和循环.sln /p:Configuration=Debug /p:Platform=x64
   ```

## 速记卡

| 知识点 | 记这一句 |
| --- | --- |
| 真假 | 0 为假，非 0 为真 |
| 悬空 else | else 配最近那个没配对的 if |
| 相等判断 | 写成 `3 == x` 防手滑 |
| 区间判断 | 用 `&&` 连接，不能连写 |
| switch | 整型表达式 + break 刹车 |
| do-while | 至少执行一次 |
| continue | while 里小心死循环 |
| goto | 能不用就不用 |
